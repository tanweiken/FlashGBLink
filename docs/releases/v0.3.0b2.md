**Experimental pre-release of the SO ready-line performance line, now with the
CRC32 delta work from `main` 0.2.3.** Plugin `0.3.0b2`; `main` stays on 0.2.3.

`0.3.0b1` started pacing the link port by the GBA's SO ready line — high while
busy, low once the next word is loaded — so the Pico clocks as soon as the GBA
is ready instead of waiting a fixed 150 µs per word. `0.3.0b2` adds the payload
CRC32 command from `main`: a sector diff and a post-program verify are computed
on the cartridge bus, so they no longer cross the link.

## Speed

Measured components on the tested 32 MiB `M36L0R8060B` bootleg cartridge with a
4 MiB Apotris image:

| Operation | 0.2.x (read verify) | Measurement |
|---|---|---|
| 4 MiB read | 160 s | 45 s (SO pacing) |
| 4 MiB verified write, CLI | 6:03 | 2:13 (SO pacing, read verify remains) |
| cold 4 MiB diff | 2.5 min | 21–22 s (CRC32) |
| repeat write, unchanged image | full write | 0.55 s (state probes) |
| verify per 128 KiB sector | 4.3–4.7 s | 0.54 s (CRC32) |
| FlashGBX compare per 128 KiB | read-back | 0.60 s (`CALC_CRC32`) |

The combined b2 build has not been re-timed end to end; expect the verified
write to drop further because its verify read is replaced by the CRC.

## Install

All three parts have to come from this release — the payload, the plugin and the
firmware are a matched set:

1. **Flash the Pico** with `gbasend-pico.uf2` below (or `gbasend-pico-rgb.uf2`
   for a board with a WS2812 LED on GP16). Hold BOOTSEL, copy to `RPI-RP2`.
2. **Install the plugin**: extract `FlashGBLink-plugin.zip` below into
   FlashGBX's `plugins/` directory. It already contains the matching GBA
   payload.
3. **Build `gbasend`** from <https://github.com/tanweiken/gbasend-rs> at commit
   `a1257e4`. Upstream `nullstalgia/gbasend-rs` does not carry the handshake, so
   its nootloader and speed test do not match this firmware.

For delta writes from FlashGBX, enable **Config → Skip writing matching ROM
chunks**. The plugin answers `CALC_CRC32` now, so matching sectors are skipped
in about 0.6 s per 128 KiB.

## Compatibility

- `main` (0.2.3) and upstream `gbasend` are unaffected; do not mix a payload
  from one line with firmware from the other.
- The handshake only engages at or above 1 Mbaud. The BIOS multiboot upload
  (256 kHz), a session opened below 1 Mbaud, and an older payload all keep the
  fixed delay, so mixed installs stay safe but get no speedup.
- Validated on the M36 cartridge above only; other profiles are not yet tested.
